F1. **Six deep links share one accessible name while targeting six different `?service=` values (a11y observation O-1, advisory, non-blocking).** Every entry link reads "Book a consultation — the form opens with this service chosen." but each href carries a distinct `services[].title`. It passes WCAG 2.2 AA 2.4.4 (the entry's `h3` is the programmatic context) but fails AAA 2.4.9 (link purpose from link text alone). Not a blocker; a refinement for clarity when a link is read in isolation.
Severity: minor (optional — Orchestrator decides disposition). Fix: give each entry link a distinct accessible name, e.g. `aria-label="Book a consultation — the form opens with {service.title} chosen."`, or prefix the visible text with the service title.
