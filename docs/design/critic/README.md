# Critic reviews

Every critic verdict is saved here as `<topic>-<YYYY-MM-DD>.md`.

- A phase may only be marked done when the relevant review ends in **APPROVE**, or the Orchestrator logs a documented override after 3 REJECT rounds (see `STUDIO_CHARTER.md`).
- Reviews are append-only. Never edit an old review; write a new one for a re-review and reference the round number.
